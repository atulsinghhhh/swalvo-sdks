Swalvo Media Demo

Real WebRTC media through Swalvo's managed RTC infrastructure — not a mock. This page is built entirely on @swalvo/rtc's public API; nothing here talks to the underlying media server directly (see app.js). A token is minted for you by the small backend in server.py — see the README for how to run it. Open this page in multiple tabs with different identities (same room) to test a group call.
